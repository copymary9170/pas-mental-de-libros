# Abandonados

Obras que empece pero decidi no continuar, ya sea por falta de interes, ritmo lento, mala experiencia o porque simplemente no era el momento.

| Titulo | Tipo | Motivo | Hasta donde llegue | Fecha |
|---|---|---|---|---|
|  |  |  |  |  |

## Motivos comunes

- No me engancho
- Se puso aburrido
- No conecte con los personajes
- El ritmo era muy lento
- No era lo que esperaba
- Lo deje para retomarlo algun dia
