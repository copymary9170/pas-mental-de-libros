# Criterios automaticos de personajes

Este archivo explica como se deben medir premios de personajes y como agruparlos cuando aparecen en obras distintas, fanfictions, adaptaciones o versiones alternativas.

## Regla principal

Un personaje no se identifica solo por el nombre.

Para evitar confusiones, cada registro debe considerar:

- Nombre del personaje
- Obra / version
- Tipo de obra
- Contexto: canon, fanfiction, AU, adaptacion, remake, relectura o rewatch
- Autor / creador si aplica

Ejemplo:

| Nombre | Obra / version | Tipo | Contexto | Se agrupa automaticamente? |
|---|---|---|---|---|
| Personaje A | Obra canon | Anime | Canon | Si, con su compendio base |
| Personaje A | Fanfic X | Fanfiction | AU | Posible, si es claramente la misma version/base |
| Personaje A | Otra obra distinta | Libro | Canon distinto | No automaticamente |

## Identidad del personaje

Para los premios se usan dos niveles:

| Nivel | Que significa | Para que sirve |
|---|---|---|
| Personaje por obra | El personaje dentro de una obra/version especifica | Premios justos dentro de cada entrada |
| Compendio de personaje | Todas las versiones reconocibles del mismo personaje | Ver logros acumulados del personaje |

## Premios por personaje dentro de una obra

Estos premios se calculan usando `Personajes por capitulo`, `Momentos fuertes de personajes`, `Evolucion de personajes` y la tabla de capitulos.

| Premio | Como se determina |
|---|---|
| Personaje favorito mas constante | Aparece mas veces como favorito por capitulo dentro de la misma obra |
| Personaje que se robo mas capitulos | Aparece muchas veces como destacado o favorito |
| Personaje que empezo flojo y termino fuerte | Descripcion inicial regular/negativa y final positiva |
| Personaje que se cayo al final | Descripcion inicial positiva y final negativa/decepcionante |
| Personaje con mejor evolucion | Cambio positivo claro entre inicio, mitad y final |
| Personaje con peor evolucion | Cambio negativo claro entre inicio, mitad y final |
| Personaje revelacion | Poca importancia al inicio, luego favorito o destacado |
| Personaje que mas cambio mi opinion | Campo `Cambio de opinion` fuerte o repetido |
| Mejor villano | Rol villano o villano destacado + nota alta, impacto fuerte o muchas menciones |
| Villano que mas destaco | Rol villano + muchas menciones positivas o nota alta |
| Villano mas odiado | Rol villano + nivel de odio alto o muchas ganas de matarlo simbolicamente |
| Villano que amo odiar | Villano con odio alto pero tambien nota alta o comentario positivo sobre lo bien escrito |
| Secundario que se robo la obra | Rol secundario + muchas menciones como favorito/destacado |
| Personaje que llore con su muerte | Momento tipo muerte + llanto activo o comentario de llanto |
| Muerte de personaje que mas me dolio | Momento tipo muerte + intensidad alta + llanto/comentario fuerte |
| Personaje que me dio mas orgullo | Momento tipo orgullo/victoria/redencion + intensidad alta |
| Orgullo mas grande por un personaje | Varios momentos de orgullo o uno con intensidad alta |
| Personaje que mas me hizo sonrojar | Campo `Me hizo sonrojar` repetido o momento tipo sonrojo con intensidad alta |
| Sonrojo mas fuerte | Momento tipo sonrojo + intensidad alta + comentario claro |
| Personaje que mas odio | Mayor nivel de odio acumulado en capitulos o momentos fuertes |
| Personaje que mas quise matar simbolicamente | Mayor cantidad en `Veces que quise matarlo` o momentos tipo ganas de matarlo |
| Personaje mas insoportable | Odio alto + comentarios de irritacion, rabia o desesperacion |
| Personaje mas frustrante | Cambios de opinion negativos repetidos o comentarios de malas decisiones |
| Personaje mas protector | Descripciones repetidas de proteccion, cuidado o sacrificio |
| Personaje mas peligroso para mi estabilidad | Muchas menciones de obsesion, sonrojo, lujuria, odio o caos emocional |

## Premios por compendio de personaje

Estos premios se calculan agrupando apariciones del mismo personaje en diferentes obras o versiones, pero solo cuando la coincidencia sea clara o probable.

| Premio | Como se determina |
|---|---|
| Personaje con mas logros acumulados | Mas premios o menciones en distintas obras/versiones |
| Mejor version del personaje | Version con mejor nota, mejor opinion o mas premios |
| Version que mas me hizo sufrir | Version con mas llanto, muerte, trauma o comentario doloroso |
| Version que mas me hizo sonrojar | Version con mas momentos de sonrojo/lujuria |
| Version que mas orgullo me dio | Version con mas momentos de orgullo/victoria/redencion |
| Version que mas odie | Version con mas odio acumulado o ganas de matarlo simbolicamente |
| Version con mejor villania | Version marcada como villano destacado con mas impacto |
| Personaje mas constante entre versiones | Aparece bien valorado en canon, fanfiction y otros registros |
| Personaje que el fanfiction mejoro | Version fanfiction supera a la canon segun opinion o nota |
| Personaje que el fanfiction destruyo | Version fanfiction baja la opinion o genera decepcion |
| Personaje que siempre vuelve a ganar | Gana premios en varias obras/versiones |

## Cringe de la historia

El cringe se mide como sensor de la obra/historia completa, no necesariamente de un personaje, aunque tambien puede aparecer como momento fuerte.

| Premio | Como se determina |
|---|---|
| Historia con mas cringe | Sensor de cringe activo + mayor nivel de cringe |
| Cringe mas divertido | Tipo de cringe divertido o delicioso + opinion positiva |
| Cringe mas incomodo | Tipo de cringe incomodo o vergüenza ajena + nivel alto |
| Cringe que casi me saca de la historia | Nivel de cringe alto + comentario negativo o pausa/abandono |
| Cringe que funciono | Cringe activo + nota buena u opinion positiva |
| Tesoro cringe del año | Cringe activo + sensor tesoro oculto activo o comentario de rareza divertida |

## Similitud de nombre

La similitud del nombre solo sirve para proponer una posible agrupacion, no para confirmar automaticamente.

| Caso | Accion |
|---|---|
| Mismo nombre + misma obra base | Agrupar como probable |
| Mismo nombre + fanfiction basada en la misma obra | Agrupar como probable |
| Mismo nombre + obra distinta sin contexto | No agrupar automaticamente |
| Nombre parecido + misma obra/contexto | Agrupar como posible |
| Alias conocido + misma obra/contexto | Agrupar como probable |
| Nombre igual pero personaje distinto | Mantener separado |

## Certeza de agrupacion

| Nivel | Significado |
|---|---|
| No relacionado | Mismo nombre o parecido, pero no hay evidencia de que sea el mismo |
| Posible coincidencia | Nombre parecido o contexto parecido, pero falta confirmar |
| Probable version | Mismo personaje en fanfiction/adaptacion/AU con contexto claro |
| Confirmado | El registro dice claramente que es el mismo personaje o version |

## Datos que conviene registrar

En cada entrada, especialmente fanfiction, conviene anotar:

- Obra / version
- Si es canon, fanfiction, AU, adaptacion o remake
- Nombre del personaje
- Alias si aplica
- Obra base del personaje
- Si esta version cambia mucho al personaje
- Si esta version cuenta para el compendio
- Nivel de odio si aplica
- Veces que quise matarlo simbolicamente si aplica
- Si fue villano destacado
- Nivel de cringe de la historia si aplica

## Regla de seguridad

Si no estoy seguro de que dos personajes sean el mismo, no los fusiono como definitivo.

Los marco como:

- Posible coincidencia
- Probable version
- Confirmado

Asi el Wrapped puede decir: **este logro parece pertenecer al mismo personaje**, sin inventar una union falsa.
