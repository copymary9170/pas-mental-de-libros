# 🏆 Wrapped y reportes

Esta carpeta sirve para hacer un resumen tipo **wrapped** de todo lo que lei, vi, termine, abandone o deje pendiente.

El objetivo es mirar el año completo como si fuera un resumen personal: favoritos, estadisticas, obsesiones, decepciones, mejores personajes y obras que mas me marcaron.

## Que puede incluir un wrapped

- Obras terminadas del año
- Obras empezadas pero no terminadas
- Obras abandonadas
- Favoritos absolutos
- Mejores personajes
- Mejores ships
- Mejor final
- Peor final
- Obra que mas me destruyo emocionalmente
- Obra que mas me sorprendio
- Obra que mas me decepciono
- Generos mas repetidos
- Mes con mas actividad
- Frases o escenas memorables
- Pendientes que quiero retomar

## Diferencia entre wrapped y reporte

| Tipo | Para que sirve |
|---|---|
| Wrapped | Resumen emocional y divertido del año |
| Reporte | Revision mas ordenada por mes, trimestre, estado o tipo de obra |

## Archivos recomendados

- `2026-wrapped.md`
- `2026-reporte-anual.md`
- `2026-resumen-emocional.md`
- `2026-pendientes-para-retomar.md`

## Regla importante

No borres las listas principales para hacer el wrapped. Usa este espacio como resumen final, no como reemplazo de `listas/`, `entradas/` o `ranking/`.
