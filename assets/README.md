# Assets visuales

Esta carpeta guarda las imagenes que despues se pueden usar en el Wrapped, rankings, reportes y fichas de obras.

La idea es que el Wrapped final no sea solo texto, sino algo visual tipo Spotify Wrapped, TV Time, Letterboxd o resumen anual con tarjetas.

## Carpetas recomendadas

| Carpeta | Uso |
|---|---|
| `assets/portadas/` | Portadas de obras, posters, covers o imagen principal |
| `assets/personajes/` | Fotos o imagenes de personajes |
| `assets/ships/` | Imagenes de parejas o duos |
| `assets/escenas/` | Capturas de escenas importantes |
| `assets/wrapped/` | Imagenes ya seleccionadas para el Wrapped final |
| `assets/ranking/` | Imagenes para rankings visuales |

## Como nombrar imagenes

Usa nombres simples, sin espacios, para que sea facil enlazarlas.

Ejemplos:

- `assets/portadas/nombre-obra.jpg`
- `assets/personajes/nombre-obra-personaje.jpg`
- `assets/ships/nombre-obra-personaje-a-personaje-b.jpg`
- `assets/escenas/nombre-obra-capitulo-05.jpg`

## Regla importante

No basta con subir una imagen: tambien debe quedar asociada a una obra, personaje, capitulo o premio.

Para eso se usa `wrapped/imagenes-wrapped.md`.
