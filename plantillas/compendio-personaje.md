Este archivo sirve para agrupar todas las apariciones, versiones y logros de un mismo personaje en diferentes obras, fanfictions, adaptaciones o registros.

La clave es no confundir personajes solo porque tienen el mismo nombre. Siempre se toma en cuenta:

- Nombre del personaje
- Obra / version
- Tipo de obra
- Autor / creador si aplica
- Contexto: canon, fanfiction, adaptacion, AU, remake, relectura, rewatch

## Regla de agrupacion

Si dos personajes tienen el mismo nombre pero no son la misma persona/version reconocible, no se agrupan automaticamente.

Si parecen ser el mismo personaje en diferentes versiones, se agrupan como **posible coincidencia** hasta que haya suficiente contexto para confirmarlo.
