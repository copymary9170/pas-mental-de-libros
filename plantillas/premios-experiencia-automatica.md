# 🧠 Premios automaticos de experiencia

Estos premios estan pensados para que se puedan determinar con datos del repositorio, no para llenarlos todos manualmente.

Se calculan revisando fechas, registros diarios, cambios de estado, cantidad de capitulos/episodios/paginas, opiniones y sensores opcionales.

## Premios por estreno y tiempo

| Premio | Ganador | Como se calcula | Certeza |
|---|---|---|---|
| La vi apenas se estreno |  | Fecha de inicio entre 0 y 7 dias despues del estreno/publicacion |  |
| La vi con poco tiempo de estrenarse |  | Fecha de inicio entre 8 y 45 dias despues del estreno/publicacion |  |
| Estreno reciente tardio |  | Fecha de inicio entre 46 y 90 dias despues del estreno/publicacion |  |
| Llegue tarde pero valio la pena |  | Mas de 90 dias entre estreno e inicio + nota alta/opinion positiva |  |
| Llegue tarde y no entendi el hype |  | Mas de 90 dias entre estreno e inicio + nota baja/opinion negativa |  |
| La termine en tiempo record |  | Pocos dias entre inicio y finalizacion segun cantidad de capitulos/paginas |  |
| Obra que debi terminar antes |  | Mucho tiempo entre inicio y finalizacion + opinion final positiva |  |

## Niveles de certeza

- No determinado: no hay datos suficientes.
- Posible ganador: hay una señal, pero faltan datos.
- Ganador probable: hay varias señales, pero falta confirmacion.
- Ganador claro: fechas, registros y opinion coinciden.
